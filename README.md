# 🧠 Lista de Exercícios — Lógica de Programação  

Este repositório contém minha lista de **exercícios resolvidos de Lógica de Programação**, implementados em **Java**.  

O objetivo é registrar minha evolução e praticar lógica, estruturas condicionais, operadores e cálculos básicos utilizando diferentes linguagens.

---

## 🚀 Linguagens utilizadas
- ☕ Java  
---

1️⃣ Soma entre A e B, comparando com C

3️⃣ Igualdade entre A e B (soma ou multiplicação)  
4️⃣ Antecessor e sucessor

13️⃣ Maioridade  
14️⃣ Troca de valores entre A e B  
15️⃣ Cálculo de idade em anos, meses e dias  
16️⃣ Tipo de triângulo
